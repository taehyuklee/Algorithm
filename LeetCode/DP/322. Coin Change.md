# Coin Change — `inf`가 전파되는 과정 구체적인 예시

예제를 이렇게 잡아보자.

```python
coins = [2, 5]
amount = 7
```

DP 정의:

```text
f[i] = 금액 i를 만들기 위한 최소 동전 개수
```

초기값:

```python
f = [inf] * (amount + 1)
f[0] = 0
```

따라서 처음에는:

```text
금액:  0    1    2    3    4    5    6    7
f   :  0   inf  inf  inf  inf  inf  inf  inf
```

---

## i = 1

사용 가능한 coin을 본다.

### coin = 2

```text
1 - 2 = -1
```

음수이므로 이 coin은 현재 사용할 수 없다.

```python
if i - coin >= 0:
```

조건을 통과하지 못하고 skip.

### coin = 5

```text
1 - 5 = -4
```

역시 skip.

따라서:

```text
f[1] = inf
```

그대로 남는다.

의미:

```text
2원짜리와 5원짜리 동전으로
1원을 만들 방법이 없음
```

현재 DP:

```text
금액:  0    1    2    3    4    5    6    7
f   :  0   inf  inf  inf  inf  inf  inf  inf
```

---

## i = 2

### coin = 2

```text
2 - 2 = 0
```

이전 상태:

```text
f[0] = 0
```

따라서:

```text
f[2] = min(
    inf,
    f[0] + 1
)

= min(inf, 1)

= 1
```

즉:

```text
2 = 2
```

동전 1개로 만들 수 있다.

### coin = 5

```text
2 - 5 < 0
```

skip.

현재 DP:

```text
금액:  0    1    2    3    4    5    6    7
f   :  0   inf   1   inf  inf  inf  inf  inf
```

---

# i = 3 — 여기서 `inf` 전파가 보임

### coin = 2

```text
3 - 2 = 1
```

범위 자체는 유효하다.

즉:

```python
i - coin >= 0
```

은 통과한다.

그런데 이전 상태를 보면:

```text
f[1] = inf
```

이다.

즉:

```text
1원을 만들 수 없었음
```

여기에 2원짜리 동전 하나를 붙여서 3원을 만들려고 하면:

```text
f[1] + 1
```

인데,

```text
inf + 1 = inf
```

이므로:

```python
f[3] = min(
    inf,
    inf + 1
)
```

결국:

```text
f[3] = inf
```

그대로다.

### coin = 5

```text
3 - 5 < 0
```

skip.

최종:

```text
f[3] = inf
```

의미:

```text
3원을 만들려면 마지막에 2원을 썼다고 가정할 수는 있지만,

그 직전 금액인 1원을 애초에 만들 수 없었기 때문에

3원도 그 경로로 만들 수 없다.
```

즉:

```text
1원을 만들 수 없음
        ↓
f[1] = inf
        ↓
3원을 만들 때 coin=2 선택
        ↓
f[1] + 1
        ↓
inf + 1
        ↓
inf
```

이게 **불가능 상태가 다음 상태로 전파되는 것**이다.

# i = 4

### coin = 2

```text
4 - 2 = 2
```

이전 상태:

```text
f[2] = 1
```

따라서:

```text
f[4]
= f[2] + 1
= 1 + 1
= 2
```

즉:

```text
4 = 2 + 2
```

동전 2개.

### coin = 5

```text
4 - 5 < 0
```

skip.

현재:

```text
금액:  0    1    2    3    4    5    6    7
f   :  0   inf   1   inf   2   inf  inf  inf
```

---

# i = 5

### coin = 2

```text
5 - 2 = 3
```

그런데:

```text
f[3] = inf
```

따라서:

```text
f[3] + 1
= inf
```

이 경로로는 5원을 만들 수 없다.

하지만 아직 다른 coin이 있다.

### coin = 5

```text
5 - 5 = 0
```

그리고:

```text
f[0] = 0
```

따라서:

```text
f[5]
= min(
    inf,
    f[0] + 1
)

= 1
```

즉:

```text
5 = 5
```

동전 하나로 만들 수 있음.

이 부분이 중요하다.

```text
어떤 이전 상태가 inf라고 해서
현재 상태가 무조건 inf가 되는 것은 아님.

다른 coin을 사용한 경로가 가능할 수도 있다.
```

즉:

```text
coin = 2 경로
f[3] = inf
→ 불가능

coin = 5 경로
f[0] = 0
→ 가능

그래서 f[5] = 1
```

# i = 6

### coin = 2

```text
6 - 2 = 4
```

```text
f[4] = 2
```

따라서:

```text
f[6] = f[4] + 1
     = 3
```

즉:

```text
6 = 2 + 2 + 2
```

### coin = 5

```text
6 - 5 = 1
```

그런데:

```text
f[1] = inf
```

따라서:

```text
f[1] + 1
= inf
```

이 경로는 불가능.

최종:

```text
f[6] = min(3, inf)
     = 3
```

즉:

```text
가능한 경로 하나와
불가능한 경로 하나가 있으면

가능한 쪽을 선택한다.
```

# `inf` 전파 핵심

예를 들어:

```text
f[1] = inf
```

라는 것은:

```text
1원을 만들 수 없다
```

는 뜻이다.

그런데 3원을 만들 때 마지막에 2원짜리 동전을 쓴다고 생각하면:

```text
직전 상태
= 3 - 2
= 1
```

이므로:

```text
f[3] 후보
= f[1] + 1
= inf + 1
= inf
```

즉:

```text
이전 상태가 불가능
↓
그 상태에 coin 하나를 추가한 경로도 불가능
```

이렇게 불가능이 전파된다.

---

# 하지만 `inf`가 하나 있다고 현재 상태 전체가 불가능한 것은 아니다

예:

```text
f[5]
```

를 구할 때:

```text
coin = 2

f[5 - 2]
= f[3]
= inf
```

이 경로는 불가능.

하지만:

```text
coin = 5

f[5 - 5]
= f[0]
= 0
```

이 경로는 가능.

따라서:

```text
f[5]
= min(
    inf,
    0 + 1
)

= 1
```

즉:

```text
모든 coin 경로가 inf
→ f[i]도 inf

하나라도 가능한 경로가 존재
→ 숫자로 갱신
```

---

# 의미론적으로 기억하기

```text
f[i] = inf
```

는 그냥 큰 숫자라는 의미가 아니라:

```text
"현재까지는 금액 i에 도달할 방법을 찾지 못했다."
```

라는 상태다.

그리고:

```python
f[i - coin] + 1
```

은:

```text
"i-coin까지 갈 수 있었다면
coin 하나를 추가해서 i까지 갈 수 있다."
```

라는 의미다.

따라서:

```text
f[i - coin] = inf
```

이면:

```text
i-coin까지 애초에 갈 수 없었음
↓
거기에 coin 하나를 붙이는 경로도 존재하지 않음
↓
후보는 여전히 inf
```

---

# 한 줄 사고 흐름

```text
이전 금액에 도달 가능?
       ↓
   f[i-coin]
    /      \
 숫자       inf
  ↓          ↓
coin 추가    애초에 불가능
  ↓          ↓
+1 가능      inf 유지
```

## 가장 중요한 한 문장

> `inf`는 "아직 그 금액을 만들 수 없다"는 상태이고, 불가능한 이전 상태에서 coin 하나를 추가한다고 해서 가능한 상태가 되지는 않기 때문에 `inf`가 그대로 전파된다. 다만 다른 coin을 통해 가능한 이전 상태가 존재하면 그 값으로 갱신된다.
